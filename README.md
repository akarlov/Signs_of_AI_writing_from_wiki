# Signs of AI Writing — редакционный навык

Навык для русскоязычных редакций крупных медиа: аудит и устранение шаблонных признаков машинного письма **без искажения фактов**.

Основа: [Wikipedia:Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing). Это каталог наблюдений, **не доказательство** происхождения текста и не инструмент обнаружения водяных знаков.

## Использование

Подключите репозиторий как skill или предоставьте агенту `SKILL.md` и папку `references/`.

Команды:
- «Проведи аудит текста по skill, без переписывания».
- «Отредактируй текст по skill; сохрани все цитаты, даты, цифры и ссылки».
- «Проверь редакционные риски и выдай таблицу изменений».

По умолчанию — **аудит**, не автоматическое переписывание.

## Содержание

## Границы метода

Отдельное слово, тире или стилистическая конструкция не устанавливают авторство. Навык улучшает текст, а не гарантирует прохождение AI-detectors. Требует человеческой проверки первоисточников и юридически значимых формулировок.
